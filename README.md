# Swarnabha Banerjee — Portfolio

A modern, responsive developer portfolio built with a focus on minimal design, clear presentation, subtle interactions, and a polished user experience.

## Live Demo

**[portfolio-swarnabha.vercel.app](https://portfolio-swarnabha.vercel.app/)**

## Features

- Responsive, mobile-first design
- Dark-first minimal interface with subtle visual lighting
- Smooth animations and viewport-based transitions
- Interactive navigation with active section highlighting
- Project showcase with a dedicated flagship project
- Detailed project case study pages
- Engineering journey timeline
- Functional Hire Me contact form
- Web3Forms integration for contact submissions
- hCaptcha spam protection
- Toast-based form feedback
- Light and dark theme support
- Dedicated Privacy Policy page
- Resume download
- Accessible navigation and interactive elements

## Tech Stack

### Core

- **Next.js** — React framework and application architecture
- **React** — UI development
- **JavaScript** — Application language
- **Tailwind CSS** — Styling and responsive layouts

### UI & Interaction

- **Framer Motion** — Animations and viewport-based transitions
- **Lucide React** — Interface icons
- **React Icons** — Additional icon support
- **next-themes** — Theme management
- **React Toastify** — Form submission feedback

### Forms & Security

- **Web3Forms** — Contact form processing and delivery
- **hCaptcha** — Spam and abuse prevention

### Deployment

- **Vercel** — Production deployment
- **GitHub** — Source control and repository hosting

## Purpose

This portfolio is built to present my development work, technical capabilities, projects, and engineering journey through a clean and focused digital experience.

The design prioritizes **clarity over decoration**, combining minimalism, editorial composition, subtle motion, and responsive layouts to keep the focus on the work itself.
